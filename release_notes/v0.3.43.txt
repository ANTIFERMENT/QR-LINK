QR LINK 0.3.43

[+] Очередь: при сохранении снимка очереди новые статусы из SQLite объединяются с ним до очистки журнала. Это защищает результаты передачи от перезаписи устаревшим состоянием.
[+] При резервном сохранении статуса без SQLite явно сохраняется обновлённый статус, даже если в базе осталась старая запись.
[+] Приём: повторное предложение файла с прежним ID и другим MIME теперь отклоняется как конфликт, вместо смешивания метаданных.
[+] QR: ограничена длина внешнего ввода сканера (до 4096 символов), чтобы не обрабатывать чрезмерно длинные URI.
[+] OTA: перед публикацией проверяется точный applicationId dev.xarkon.link и положительный versionCode. Добавлен тест на отклонение чужого пакета.
[+] CI: перед сборкой релизного APK выполняются офлайн-тесты инструментов OTA. Ошибка теста останавливает выпуск.
[=] Сохранены формат QR, протокол передачи, оформление, существующие функции, сертификат подписи и постоянный адрес OTA.
[!] Исправления требуют проверки GitHub Actions. Передача между физическими телефонами, скорость и восстановление после сбоев питания в этом цикле не тестировались.
