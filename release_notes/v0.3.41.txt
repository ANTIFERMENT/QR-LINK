QR LINK 0.3.41

[+] Исправлена обработка устаревших системных событий подключения Wi-Fi: результаты отменённого или заменённого запроса больше не должны изменять активный маршрут.
[+] При потере Wi-Fi-соединения обработчик завершает запрос, снимает привязку процесса к сети и сообщает об ошибке один раз.
[+] При ошибке подключения и истечении ожидания освобождается системный сетевой запрос; поздние ответы фонового поиска игнорируются.
[+] Адрес приёмника, полученный из DHCP, шлюза или UDP-обнаружения, принимается только из локального IPv4-диапазона.
[+] GitHub Actions теперь публикует фактический текст изменений как описание релиза и отдельный файл vX.txt, затем проверяет наличие трёх файлов релиза.
[=] Сохранены идентификатор dev.xarkon.link, постоянная подпись, формат QR, протокол передачи, собственный проводник и OTA.
[!] Публичные IPv4-шлюзы и ответы UDP-обнаружения намеренно отклоняются. На нестандартных локальных сетях может потребоваться другой маршрут.
[!] Wi-Fi Direct, точка доступа, восстановление соединения и скорость на физических Android-устройствах не тестировались. Компиляция и публикация должны быть подтверждены отдельно по GitHub Actions.
