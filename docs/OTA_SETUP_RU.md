# QR LINK 0.3.9 · Инструкция OTA (официальный релизный канал)

## Что подготовлено
- Репозиторий `ANTIFERMENT/QR-LINK` теперь публичный.
- GitHub Actions автоматически собирает APK, подписывает его постоянным сертификатом и выпускает GitHub Release.
- Обновлённый QR LINK содержит встроенный неизменяемый OTA URL и отпечаток релизного сертификата.
- OTA-клиент проверяет номер версии, идентификатор приложения, размер, SHA-256 и подпись APK.
- При запуске новой версии проверка доступных обновлений выполняется не чаще раза в сутки.
- Тесты вспомогательных компонентов GitHub Actions прошли. Android-сборка пока не выполнена.

## Два действия до первого APK

**1. Загрузить ZIP исходников 0.3.9**

Ссылка: https://github.com/ANTIFERMENT/QR-LINK/upload/main

Используй подготовленный в ChatGPT файл **QR_LINK_SOURCE.zip**, содержащий обновлённые исходники. Загрузи его **в корень репозитория**, с точным именем, и нажми Commit changes. Не нужно распаковывать его вручную: workflow `ota-release.yml` запускает `scripts/import_source_zip.py`.

**2. Создать один Secret для подписи**

Ссылка: https://github.com/ANTIFERMENT/QR-LINK/settings/secrets/actions

Выбери **New repository secret**.

- Name: `QR_LINK_SIGNING_BUNDLE`
- Secret: скопируй **всю строку** из файла `QR_LINK_SIGNING_BUNDLE_BASE64.txt` внутри отдельно подготовленного **QR_LINK_PRIVATE_SIGNING_BACKUP_KEEP_SECRET.zip**.

В этом приватном архиве находятся закрытый ключ `qr-link-release.p12`, пароли, публичный сертификат, внутренний ZIP и однострочная Base64 копия для Secret. **Никогда не загружай архив ключа или текст Base64 в публичный репозиторий или Issues.** Храни отдельную защищённую резервную копию. Срок действия сертификата примерно 27 лет.

## Запуск Actions

После действий выше открой:

https://github.com/ANTIFERMENT/QR-LINK/actions/workflows/ota-release.yml

Запусти **Run workflow**, если запуск ещё не начался после загрузки ZIP. При успешной сборке GitHub создаст релиз `v0.3.9` с файлами:

- `QR-LINK.apk` для установки на телефон;
- `update.json` с метаданными и SHA-256.

Страница выпусков: https://github.com/ANTIFERMENT/QR-LINK/releases

Манифест: https://github.com/ANTIFERMENT/QR-LINK/releases/latest/download/update.json

## Сертификат и первая установка

SHA-256 сертификата релизов:

`2651D90F5C57F2D4A121E2D8B0899680343DC9E87E515ED5E100FC3D62C6D626`

Он закреплён непосредственно в исходниках Android-приложения. Чужим сертификатом выпустить обновление без изменения кода нельзя.

**Приватный ключ никогда не вшивается в APK**, поскольку это сделало бы подпись небезопасной.

Если QR LINK 0.3.8 ранее устанавливался из Code on the Go и имеет другой debug-ключ, Android не позволит поставить 0.3.9 поверх него. Сначала сохрани нужные данные, затем удали старое приложение и установи официальный 0.3.9 с GitHub Releases. Следующие версии под этим же сертификатом смогут обновляться поверх 0.3.9.

## Проверка

1. Дождись завершения GitHub Actions со статусом success.
2. Установи официальный APK из Releases.
3. Зайди в **Настройки → Обновления приложения → Проверить обновления**. При актуальной версии будет сообщение об отсутствии более новой.
4. В следующем выпуске увеличь `versionCode` и `versionName` в Gradle, загрузи новую версию источников, GitHub выпустит новый Release, а приложение сообщит об обновлении.
